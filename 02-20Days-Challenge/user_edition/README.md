# 课表提醒 用户版

这是「课表邮件提醒」程序的**分发给其他同学使用的版本**。

主程序（作者自用版）见上级目录 `../main.py`。

---

## 有什么区别

| | 作者自用版（`../main.py`） | 用户版（本目录） |
|---|---|---|
| 运行方式 | 命令行 + GitHub Actions 定时 | **图形界面，双击运行** |
| 配置 | 编辑 `.env` 文件 | **界面填写，存 `config.json`** |
| 课表 | 固定 `schedule.csv` | **自由选择任意 CSV** |
| 学期起始 | 硬编码 | **界面可设置** |
| 适用人群 | 开发者 | **普通同学** |

---

## 文件说明

| 文件 | 说明 |
|---|---|
| `main_user.py` | 用户版源码（tkinter 图形界面）|
| `课表模板.csv` | 课表格式模板 |
| `使用说明.md` | **给同学的完整教程**（授权码、课表填写、常见问题）|

## 打包成 exe

用户版通过 PyInstaller 打包为单文件 exe，同学无需安装 Python。

### 打包命令

```powershell
pip install pyinstaller pandas
python -m PyInstaller --onefile --windowed --name "课表提醒" main_user.py
```

产物：`dist/课表提醒.exe`（约 34 MB）

### 为什么不把 exe 提交到仓库

- 体积较大（34 MB），会让仓库变重
- 二进制文件 Git 无法有效管理版本
- 同学通过其他渠道获取即可

如需自行打包，按上面命令执行即可。

---

## 同学的使用流程

```
1. 拿到「课表提醒.exe」和「课表模板.csv」
2. 按「使用说明.md」获取 QQ 邮箱授权码
3. 双击 exe，填邮箱和授权码
4. 填好自己的课表 CSV
5. 点「发送测试」，收到邮件即成功
```

完整教程见 **[使用说明.md](./使用说明.md)**。

## 技术实现

| 模块 | 说明 |
|---|---|
| GUI | tkinter（Python 标准库，无需额外依赖）|
| 配置存储 | `config.json`（与 exe 同目录）|
| 课表解析 | pandas 读取 CSV，支持周次表达式 |
| 邮件发送 | `smtplib.SMTP_SSL`，QQ 邮箱 465 端口 |

### 周次表达式

支持 `3;5-13;16-18` 这种写法，表示第 3、5～13、16～18 周有课。

### 学期周次计算

```python
current_week = (今天 - 学期第一周周一).days // 7 + 1
```
