# 异校同学配置指南

> 本指南用于帮助**学期起始日期与本项目不同的同学**正确配置。

---

## 一、为什么需要修改

程序通过下面的公式计算「今天是第几周」：

```
当前周次 = (今天 - 学期第一周周一) 的天数 ÷ 7 + 1
```

程序默认值：

```python
SEMESTER_START = 2026-09-07   # 本项目作者的学期起始
```

**如果同学的学校不同，这个日期可能不同，不改会算错周次，导致课表筛选出错。**

---

## 二、第一步：确认同学的学期起始

### 方法 A：直接问（推荐）

> "你们学校这学期第 1 周是几月几号？"
> 或
> "你现在是第几周？"

### 方法 B：用周次反推

**已知**：同学现在是第 `X` 周，今天日期为 `D`（星期 `W`）

```
学期第一周周一 = D - (X - 1) × 7 - (W - 1) 天
```

**举例**：

| 已知 | 计算 |
|---|---|
| 今天是 2026-11-09（周一），同学说"现在是第 10 周" | 11-09 - 9×7 - 0 = **2026-09-07** |
| 今天 2026-11-09（周一），同学说"现在是第 9 周" | 11-09 - 8×7 - 0 = **2026-09-14** |
| 今天 2026-11-09（周一），同学说"现在是第 11 周" | 11-09 - 10×7 - 0 = **2026-08-31** |

### 方法 C：教务系统查

多数教务系统的课程表页面会显示「第 N 周（MM/DD ~ MM/DD）」，直接看即可。

---

## 三、第二步：填写配置

### 程序界面「2. 课表设置」标签页

| 字段 | 填什么 |
|---|---|
| 课表文件 | 同学自己的 CSV |
| **学期第一周的周一** | **按第二步算出的日期，格式 `YYYY-MM-DD`** |
| 军训周次 | 如果同学学校有军训，填周次（如 `14,15`）；没有就留空 |

---

## 四、第三步：验证周次是否正确

### 验证方法

1. 在程序「3. 发送测试」页顶部会显示：`今天：2026-11-09 星期一 第 N 周`
2. **把它和同学自己在教务系统看到的周次对比**
3. 一致 → 配置正确
4. 不一致 → 回到第二步重新算

### 常见误差来源

| 问题 | 说明 |
|---|---|
| 同学的"第 1 周"不是周一 | 有些学校从周一开始，但有些从实际开学日算起，需问清楚 |
| 同学的周次跳过某周 | 比如考试周不算，需在课表里手动调整 |
| 时区 | 程序固定用北京时间，国内学校无影响 |

---

## 五、第四步：课表周次表达式

### 异校同学常见写法

| 学校标注方式 | CSV 周次列写法 |
|---|---|
| 第 1-16 周 | `1-16` |
| 第 1-8 周 | `1-8` |
| 第 9-16 周 | `9-16` |
| 单周 | `1;3;5;7;9;11;13;15` |
| 双周 | `2;4;6;8;10;12;14;16` |
| 第 3、5、7 周 | `3;5;7` |
| 多段组合 | `1-8;11-16` |

### 示例

同学课表显示：
- 高等数学：1-16 周，周一 1-2 节
- 数据结构：3-11 周（单周），周三 5-6 节

对应 CSV：
```csv
周次,星期,课程名,开始时间,结束时间,地点,教师
1-16,星期一,高等数学,08:00,09:40,教学楼101,张老师
3;5;7;9;11,星期三,数据结构,14:00,15:40,机房A,王老师
```

---

## 六、配置检查清单

发给异校同学前逐项确认：

- [ ] 学期第一周周一日期已确认
- [ ] 已填入程序「课表设置」页
- [ ] 程序显示的周次与教务系统一致
- [ ] 课表 CSV 填完整（7 列）
- [ ] 星期写法为 `星期一`～`星期日`
- [ ] 时间格式为 `HH:MM`
- [ ] 军训周次已确认（有则填，无则空）
- [ ] 发送测试成功收到邮件
