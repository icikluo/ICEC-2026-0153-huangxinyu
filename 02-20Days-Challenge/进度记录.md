## 六、已知问题与注意事项

| 问题 | 说明 |
|---|---|
| **网络不稳** | 访问 github.com 时通时断，push 可能失败，需重试多次 |
| **GitHub 定时延迟** | 7:30 只是目标时间，实际 7:58～8:05；11/10 之后延迟增大到 3-5 小时（平台调度问题）|
| **force push 风险** | 若出现分叉（远端有 Actions 提交），先 `git pull --rebase` 再 push |
| **授权码** | 已暴露在聊天记录中，**项目结束后需重新生成** |
| **仓库为公开** | 故日志已脱敏，截图需打码邮箱和姓名 |
| **onedir 打包** | 用户版 v1.1 为文件夹版（exe + `_internal`），不能只发 exe |
