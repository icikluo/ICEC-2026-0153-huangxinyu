# 迭代 2：课表从「按星期」升级为「按周次」

- **日期**：2026-11-02
- **触发方式**：新增完整学期课表后发现
- **涉及文件**：`schedule.csv`（重构）、`main.py`（新增周次逻辑）
- **证据**：`iterations/iteration-2.md`、本地运行日志

---

## 一、问题

### 现象

程序上线后（迭代 1 版本），课表 `schedule.csv` 只有「星期」维度，不区分周次。实际核对教务系统后发现：

1. **同一星期不同周次的课程不同**
   - 星期四 7-8 节「职业生涯规划」只在 **3-6、8-11 周** 有，第 12 周起消失
   - 星期二 7-8 节：8-11 周是「形势与政策I」，12-13/16/17/18 周是「思想道德与法治」
   - 星期三 7-8 节「大学生心理健康」只在 **3、6、9、12、17 周**（每 3 周一次）

2. **军训周（第 14、15 周）所有课程停课**
   - 原始版本会把这两周当作正常周，发出错误的课表

3. **星期维度不足以表达学期课表**
   - 按星期硬编码会导致第 12 周之后把「职业生涯规划」当成还要上课

### 影响

- 第 12 周之后发出错误课表（多出已经不存在的课、缺少新开的课）
- 军训周会发出错误课表
- 「今日课程数」统计失真，日志数据不可信

---

## 二、定位过程

| 观察 | 推断 |
|---|---|
| 对比第 9、10、11、12、13、16、17、18 周的单周课表 | 课程存在**增删变化**，不是每周固定 |
| 第 14、15 周整周空白 | 军训周，不是「没课」 |
| 教务系统学期视图标注了每门课的周次（如 `3-13周,16-18周`） | 周次是课程属性，必须进数据模型 |

**结论**：课表数据结构必须增加「周次」维度，程序必须计算当前是第几周。

---

## 三、根因

原始设计假设「课表 = 星期 → 课程列表」的二维关系，而实际是「周次 × 星期 → 课程」的三维关系。

**需求变更导致的模型缺陷**，属设计阶段考虑不周，非代码 bug。

---

## 四、修复

### 1. `schedule.csv` 结构升级

**旧结构**（4 列）：
```csv
星期,课程名,时间,地点
星期一,工程数学,08:40-10:00,教学楼526
```

**新结构**（7 列）：
```csv
周次,星期,课程名,开始时间,结束时间,地点,教师
3-13;16-18,星期一,工程数学,08:40,10:00,教学楼526,廖敏
```

**周次表达式约定**：
- `;` 分隔多个区间，`-` 表示范围
- 例：`3;5-13;16-18` = 第 3、5～13、16～18 周
- 例：`3;6;9;12;17` = 每周隔 3 周上一次

**时间列拆分**：`时间`（`08:40-10:00`）拆为 `开始时间` + `结束时间`，便于排序和后续扩展（如课前提醒）。

### 2. `main.py` 新增周次逻辑

```python
SEMESTER_START = date(2026, 9, 7)   # 第 1 周周一
MILITARY_WEEKS = {14, 15}           # 军训周

def current_week(today):
    """计算今天是学期第几周"""
    return (today - SEMESTER_START).days // 7 + 1

def parse_weeks(cell):
    """解析周次表达式：'3;5-13;16-18' -> {3, 5,6,...,13, 16,17,18}"""
    weeks = set()
    for token in str(cell).replace("，", ";").replace(",", ";").split(";"):
        token = token.strip()
        if not token:
            continue
        if "-" in token:
            a, b = token.split("-", 1)
            weeks.update(range(int(a), int(b) + 1))
        else:
            weeks.add(int(token))
    return weeks
```

**筛选逻辑**：
```python
if week_no in MILITARY_WEEKS:
    return [], total, True          # 军训周直接返回空
df["_weeks"] = df["周次"].apply(parse_weeks)
hit = df[(df["星期"] == weekday_name) &
         (df["_weeks"].apply(lambda s: week_no in s))]
```

### 4. 日志字段扩展

新增 `周次` 和 `模式` 两个字段，便于从日志回溯「哪天属于第几周、是否是军训周」。

**旧**：
```

```

```

```

## 七、经验与后续

1. **需求要先穷尽再建模型**：第一版只问了「星期」，没问「周次」，导致上线后要重构数据模型。
2. **把学期起点做成常量**：`SEMESTER_START = date(2026, 9, 7)` 集中管理，换学期只需改一处。
3. **特殊周次用集合表达**：`MILITARY_WEEKS = {14, 15}` 比在 CSV 里写「军训」行更清晰，避免污染课程数据。
4. **日志加字段是低成本的排查手段**：加了 `周次` 和 `模式` 后，从日志就能回溯「哪天是第几周」。
5. **后续可扩展**：CSV 已拆出 `开始时间`/`结束时间`，为「课前 30 分钟二次提醒」预留了数据基础。
