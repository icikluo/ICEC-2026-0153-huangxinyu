## 四、字段说明

| 字段 | 说明 | 示例 |
|---|---|---|
| `周次` | 该课程在第几周上。多个区间用 `;` 分隔 | `3-13;16-18` 表示第 3~13 周和第 16~18 周 |
| `星期` | 星期几，必须写全称 | `星期一`、`星期二` … `星期日` |
| `课程名` | 课程名称 | `工程数学` |
| `开始时间` | 24 小时制 | `08:40` |
| `结束时间` | 24 小时制 | `10:00` |
| `地点` | 上课地点 | `教学楼526` |
| `教师` | 任课教师 | `廖敏` |

### 周次表达式写法

| 写法 | 含义 |
|---|---|
| `1-16` | 第 1 到 16 周每周都有 |
| `3;5-13;16-18` | 第 3 周 + 第 5~13 周 + 第 16~18 周 |
| `3;6;9;12;17` | 只有第 3、6、9、12、17 周（每 3 周一次）|
| `8-11` | 第 8~11 周 |
