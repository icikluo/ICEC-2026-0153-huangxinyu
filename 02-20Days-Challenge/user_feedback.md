### 用户 2

- **称呼**：同学 B
- **使用日期**：2026-11-10 18:27
- **运行环境**：Windows，程序内直接运行
- **接受程度**（1-5 分）：4
- **反馈原文**：
  > "我觉得前面挺顺利的，很容易弄好，就是在 UTF-8 形式那里卡了很久，没接触过就不知道怎么改形式，后面问豆包的哈哈哈[捂脸]。总的来说我觉得挺好用的"
- **运行结果**：发送成功，收到「今日课表提醒 2026-11-10 星期二（第 10 周）」，共 2 节课（大学英语 10:00-11:40 教学楼202 教师：李老师；形势与政策 15:10-16:30 教学楼701 教师：陈老师）
- **使用说明**：该同学的课表与用户 1 不同（英语课时间为 10:00-11:40），说明每人使用**自己的真实课表**测试
- **反馈分析**：
  - **正面**：配置流程顺畅，"挺好用的"，邮件准时送达
  - **核心问题**：**CSV 文件保存编码（UTF-8）** 是最大障碍——同学不熟悉这个操作，卡了较长时间，最后借助其他 AI 工具解决
  - **根因**：Excel 默认保存为 GBK 编码的 CSV，导致中文乱码；程序原先只支持 UTF-8
  - **改进方向**：
    1. 程序自动识别多种编码（UTF-8 / GBK / GB18030）
    2. 支持直接读取 `.xlsx`（Excel 原生格式，无编码问题）
    3. 文档中对该步骤加粗提示
- **截图**：`user2-app.png`（程序发送界面）、`user2-mail.png`（QQ 邮箱收件箱）

### 5.2 使用门槛与已知局限

| 局限 | 说明 |
|---|---|
| 需要 QQ 邮箱授权码 | 需在 QQ 邮箱设置中开启 IMAP/SMTP 服务，对不熟悉设置的同学有门槛 |
| 需要手动填课表 | 无法直接对接教务系统 API，需手动整理 CSV |
| 需 Windows 环境 | exe 仅支持 Windows |
| 需手动触发 | 程序为手动点击发送，未内置定时（可用 Windows 任务计划） |
