## 五、说明

### 5.1 真实性说明

- 所有反馈均来自真实使用，包含**截图、原始评语、使用日期**
- 反馈内容包含正面与负面意见，未做美化删改
- 用户昵称已做匿名化处理（姓名首字 + 同学 / 学号替代）

### 5.2 使用门槛与已知局限

| 局限 | 说明 |
|---|---|
| 需要 QQ 邮箱授权码 | 需在 QQ 邮箱设置中开启 IMAP/SMTP 服务，对不熟悉设置的同学有门槛 |
| 需要手动填课表 | 无法直接对接教务系统 API，需手动整理 CSV |
| 需 Windows 环境 | exe 仅支持 Windows |
| 需手动触发 | 程序为手动点击发送，未内置定时（可用 Windows 任务计划） |

### 5.3 版本信息

| 项目 | 内容 |
|---|---|
| 版本 | v1.0 |
| 打包方式 | PyInstaller --onefile --windowed |
| 体积 | 约 34 MB |
| 依赖 | 打包内置，同学无需安装 Python |
