# 课题 03 · 教学楼无线信号盲区测绘

ICEC-2026 第一阶段（基础素养实地测评）选考课题。

| 项目 | 内容 |
|---|---|
| 实验地点 | ICEC 校区 1 号楼（商贸学院） |
| 实验时间 | 2026-10-30 16:39–17:49（**第二轮**） |
| 网络 | SSID `SZIT-WLAN`，Wi-Fi 5 |
| 采样点位 | 9 个 |
| 采样组数 | 32 条记录（每点位 RSSI 4 次，其中 3 次同步测速） |
| 主指标 | **RSSI(dBm)** |
| 辅指标 | 下载/上传 Mbps、下行/上行延迟 ms、抖动、丢包 |
| 盲区判定 | **RSSI 均值 < −80 dBm** |

## 核心结论

| 点位 | RSSI | 下载 | 延迟 | 判定 |
|---|---|---|---|---|
| 两楼连接处 | −41.0 dBm | 86.2 Mbps | 42 ms | ✅ 最强（波导效应） |
| 5 楼大厅 | −48.2 dBm | 81.5 Mbps | 121 ms | ✅ 基准 |
| 露台 | −53.8 dBm | 109.4 Mbps | 66 ms | ✅ 正常 |
| 5 楼电梯口 | −65.5 dBm | 74.8 Mbps | 353 ms | ✅ 正常 |
| 8 楼电梯口 | −71.0 dBm | 70.0 Mbps | 378 ms | ⚠️ 临界 |
| 2 楼电梯口 | −71.0 dBm | 23.6 Mbps | **794 ms** | ⚠️ 临界（延迟最差） |
| **5 楼厕所** | **−82.0 dBm** | 18.2 Mbps | 610 ms | ❌ **盲区** |
| **电梯运行中** | 无读数 | 无网络 | 无网络 | ❌ **重度盲区** |
| **电梯内部** | 无读数 | 无网络 | 无网络 | ❌ **重度盲区** |

**两个关键发现**：
1. **厕所 −82.0 dBm 唯一跌破盲区线**；电梯轿厢连 RSSI 都读不出（法拉第笼）。
2. **信号达标 ≠ 体验达标**：2 楼电梯口 RSSI −71 dBm 判定"正常"，但延迟 794 ms、下载仅 23.6 Mbps——属"容量盲区"，与覆盖盲区是两种不同的病。

## 两轮实验

| | 第一轮 2026-10-28 | **第二轮 2026-10-30（本目录主数据）** |
|---|---|---|
| 主指标 | 下载速率 MB/s | **RSSI dBm** |
| 延迟 | ✗ | ✓ |
| 判定口径 | < 1 MB/s（间接） | **< −80 dBm（课题原文）** |
