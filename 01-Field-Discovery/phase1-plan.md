## 课题 03：教学楼与宿舍无线信号盲区测绘

### 一、实验目标

- 测绘校园不同遮挡特征区域的无线信号质量
- 分析墙体材质、空间结构对 WiFi 信号衰减的影响规律
- 识别信号盲区并提出优化建议

### 二、实验设计

#### 1. 采样点位选择（8 个点位）

| 点位编号 | 位置描述 | 遮挡特征 |
|---------|---------|---------|
| A1 | 信通学院 431 实训室门口 | 走廊中心 |
| A2 | 信通学院走廊转角处 | 90 度转角 |
| A3 | 宿舍楼电梯口 | 金属屏蔽环境 |
| A4 | 宿舍楼楼梯间 | 多层混凝土遮挡 |
| A5 | 教学楼窗户边（室外） | 无遮挡对比 |
| A6 | 教学楼教室内（中间） | 墙体部分遮挡 |
| A7 | 宿舍楼卫生间 | 瓷砖 + 水管干扰 |
| A8 | 图书馆走廊尽头 | 长距离衰减 |

#### 2. 测试指标

- **信号强度（RSSI）**：单位 dBm，范围 -30（极强）到 -90（极弱）
- **网络延迟（Ping）**：单位 ms
- **下载速率**：单位 Mbps
- **上传速率**：单位 Mbps

#### 3. 测试方法

每个点位连续测试 3 次，记录各项指标：

```
测试工具：
- 手机：WiFi 分析仪 APP / speedtest.net
- 电脑：ping 命令 + speedtest 命令行
- 记录时间：早（8:00-9:00）、午（12:00-13:00）、晚（19:00-20:00）
```

## 课题 10：日常数字任务耗时审计与 AI 批处理实证

### 一、实验目标

- 识别一项高频重复性数字任务
- 对比人工处理与 AI 辅助处理的耗时差异
- 制定人机校验规则

### 二、任务选择

**推荐任务：实验数据表格汇总**

针对课题 03 的测试数据，对比：
- **人工方式**：手动打开 CSV 文件 → 复制数据 → 粘贴到汇总表格 → 格式化
- **AI 方式**：编写 Python 脚本 / 使用 AI 工具自动批量汇总

### 三、实验设计

#### 1. 测试样本

准备 10 个相同的原始数据样本（可使用课题 03 的测试数据）

#### 2. 耗时记录表

| 样本编号 | 人工耗时（秒） | AI 脚本耗时（秒） | 加速倍数 |
|---------|--------------|----------------|---------|
| 1 | | | |
| 2 | | | |
| ... | | | |
| 10 | | | |

#### 3. AI 工具/脚本

```python
# 示例：批量 CSV 数据汇总脚本
import pandas as pd
import glob

# 读取所有 CSV 文件
files = glob.glob('raw_data/*.csv')
all_data = []

for file in files:
    df = pd.read_csv(file)
    all_data.append(df)

# 合并并导出
result = pd.concat(all_data, ignore_index=True)
result.to_excel('汇总报告.xlsx', index=False)
print(f"完成！共处理 {len(files)} 个文件")
```
