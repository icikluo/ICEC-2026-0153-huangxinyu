# AI 协作排障记录

本目录保存 ICEC-2026 实施过程中，**关键提问与真实报错**的原始对话留痕。

原则：

- 只收录**真的卡住过**的故障，不收录顺手的问答；
- 保留**原始报错文本**，不改写、不翻译；
- 记录里同时写清「AI 给的方案」和「我实际执行后哪些不管用」；
- token、密码、内网 IP 一律脱敏。
